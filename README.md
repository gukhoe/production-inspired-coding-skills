# Manufacturing AI Coding Skills

Coding skills that apply manufacturing production, quality, and verification processes to AI software development. The goal is to improve how code is specified, produced, checked, and changed across software domains.

Current stage: **original baseline preserved, evidence reviewed, improvements prepared**. All 16 `SKILL.md` files retain the exact bytes supplied by the user. The proposed behavioral improvements have not yet been applied.

## Recheck the evidence

Run with the Python standard library:

```sh
python -X utf8 scripts/recheck_evidence.py
```

This checks original hashes, review JSON/CSV consistency, group aggregates, and the recorded A/B/C test outcomes. It writes results to `reports/verification/`. The upstream runner, which overwrites its result file, runs only in a temporary copy. The three original sample tests also run.

**An audit PASS means the evidence is consistent and the outcomes reproduce. It does not establish evaluator validity or skill superiority.** A deliberately broken implementation that always raises an exception passes 13 of the original 18 benchmark tests.

Generated bytecode remains inside the original ZIP but is excluded from extracted working files. `.gitattributes` disables automatic line-ending conversion to preserve source hashes. Future skill changes should be recorded separately from this baseline.

## Provenance and scope

The direct skill source is `Manufacturing_AI_Process_Control_Skills_v1.zip`. Its 16 skills also match the snapshots in the separately located `Manufacturing_AI_ABC_90_Run_Study.zip`. Only relevant reports and source files from that related study are included, not the entire archive. Archive hashes reported by the earlier study are historical assertions, distinguished from hashes directly computed for the current attachments.

The B skill's MIT license is preserved in `comparators/LICENSE`; it is not applied to the manufacturing skills as a whole. The original `GITHUB_RESEARCH.md` is a historical reference list, not a new verification of the linked repositories' originality or current state.

Repository-facing documentation is in English. Original attachments, frozen experiment prompts, source code, and raw logs retain their original language and bytes for reproducibility. The rocket comparison includes an [English translation of its frozen inputs](comparisons/rocket-code/INPUTS_EN.md).
