# Software Assurance Auditor 0.3.0a2 source preview

Install from the current main checkout using [the CLI/MCP guide](MCP_SETUP.md).
This update publishes software, reusable skills, process documentation, tests and
blank standard forms. It does not publish audited projects, private results,
execution logs or graph exports. No PyPI publication is assumed.

- Common sensitive-file policy across MCP read routes, including indirect evidence.
- Review author/relationship disclosure, checkpoint-specific reused-evidence links
  and accurate handoff blockers.
- Explicit CLI witness recording with selected-source/log identity checks. It is
  not a sandbox or signed attestation; MCP remains read-only.
- SARIF 2.1.0 candidate import and a silent bare-exception rule, with bounded inputs
  and normalized output. External analyzers remain optional.
- Standard 0.3.0: 100-point area allocation, 72 question-specific evidence modes,
  scoring anchors, explicit contribution/exclusion disclosure and documented-score
  diagrams. Standard 0.2.0 scoring remains available for declared older manifests.
- Sixteen revised coding skills with local output forms and a document-evidence
  bridge. Historical skill experiments remain historical; no v2 superiority claim.
- Installed MCP, mutation, partition, drift and provenance checks in CI. The
  workflow does not upload project audit artifacts.
- Scoped MIT licensing for independently developed auditor code, with original
  research/skill and third-party licensing boundaries preserved.

Read [scoring balance](SCORING_BALANCE.md), [assurance controls](AUDIT_REVIEW_CONTROLS.md)
and [skill maintenance](SKILL_V2.md) before migrating existing reviews. Neither a
high score nor a completed checklist authorizes release. Complete runtime graph
extraction, authenticated reviewer identity and CI-attestation verification remain
outside this preview's guarantees.
