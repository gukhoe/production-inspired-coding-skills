# Software Assurance Auditor: complete questionnaire

Generated by `python scripts/export_audit_templates.py`. Standard 0.3.0.

24 criteria, 72 separately assessed checkpoints. Each checkpoint uses the 0–4 rubric; unknowns remain unscored. The challenge is a review method, not permission to run code.

## Scoring rubric

| Score | Interpretation |
|---|---|
| 0 | A current, evidenced failure or missing required control; status gap. |
| 1 | Intent/design is documented, implementation or execution is not established; status partial. |
| 2 | Control is implemented with limited/static evidence; required scenarios remain incomplete; status partial. |
| 3 | This checkpoint has substantial current evidence, but an applicable cross-check or scenario remains incomplete; status partial. Behavioral checkpoints require successful execution. |
| 4 | This checkpoint meets all its applicable acceptance conditions and cross-checks; status supported. Do not require sibling checkpoints to pass before scoring this one. Behavioral checkpoints require relevant successful execution. |
| unverified | No defensible current score. Excluded from observed score, included in coverage denominator. |
| not_applicable | Evidence-backed scope exclusion. Excluded from scoring denominators and counted separately. |
