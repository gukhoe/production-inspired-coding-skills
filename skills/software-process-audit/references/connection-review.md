# Connection review

The auditor works without Graphify or REA. Use its built-in Python mapper or inspect source in the host and declare interfaces manually. External graph imports are optional evidence.

1. Map the selected scope with `audit_scan_connections` / `map-source`. For other languages, trace both endpoints in source and record declared processes and boundaries. Completion: source identities, selected files, unresolved links and exclusions are explicit.
2. Ask the eight connection probes returned by the mapper: authority, contract, resource/time bounds, duplication, containment, transport/data, diagnosis/ownership and recurrence. Completion: relevant hypotheses have a discriminating check; automatic patterns remain candidates until reviewed.
3. Run authorized tests through host tools and link current execution evidence. Assess applicable existing checkpoints and boundary aspects; these probes do not add scored items. Completion: findings distinguish source observations, actual failures and untested hypotheses.
4. Record risks against `boundary:<id>` and map process `code_nodes` to source IDs if needed. Assign correction, owner and verification conditions. Completion: a highlighted risk can be traced to its finding and evidence.
5. Generate `audit_visualize` / `report`. Deliver the fixed report plus visual summary and improvement queue. Completion: score and coverage are shown together; missing evidence, omitted graph regions and unmapped risks stay visible.
6. After an authorized correction, re-run the failure case and a neighboring valid case. Re-evaluate current evidence and retain unresolved investigation steps. Completion: closure describes exactly what was verified, without treating graph appearance as proof.

The native mapper initially supports selected Python AST relationships and three candidate patterns: missing explicit request timeout, disabled TLS verification and shell interpretation. No matches is not a security pass. Call expressions and local import candidates are not a full runtime graph. Other languages require source review or an optional adapter.

Red marks reviewed high-impact risks or assessed gaps. Amber marks incomplete reviews or candidates. Dashed source edges are inferred/unknown. Graph reachability is an investigation aid, not causal propagation. The offline view never changes scores, closes risks or executes corrective actions.
