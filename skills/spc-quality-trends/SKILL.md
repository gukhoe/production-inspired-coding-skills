# Spc Quality Trends

1. Record defects, false passes, reruns and repair times with task, model, prompt, dependencies and environment identities.
2. Use run charts first. Split incompatible populations and mark change points; avoid control-limit or capability claims from insufficient observations.
3. Define escalation for sustained deterioration and check data completeness. Complete with a defensible trend or explicit insufficiency, not an unqualified average.

## Output and evidence

Use [the blank output form](assets/output-template.md) for this workflow and [the portable record](assets/review-record.json) when transferring it to the auditor. Fill only observed facts; link raw evidence rather than copying logs into the conversation. A completed form is a document, not execution evidence or an automatic supported score.
